# 实测范围与已知限制

以下是 2026-11-11 的实际记录，不是对任意机器、模型或项目的通过承诺。

## 桌面实测

环境：macOS、DeepSeek Harness 0.2.2-rc.1、PaiWarp 0.2.0。插件在独立目录安装；待测项目与插件目录分开。

| 项目 | 实际结果 |
| --- | --- |
| Python 标准库待办程序 | 中文、多行输入、错误编号不改文件、两次启动与退出、JSON 精确验证通过 |
| 人工接管 | Agent 写入被拒，手工 list 生效，交回后继续 |
| Python 材料 | 5 张 PNG、191.28 秒 MP4；完整解码通过；桌面播放器实际播放 |
| 图片替换 | 2 个图片地址替换，反向还原后与原文逐字节相等 |
| PaiCLI 第三章 | 构建、启动、保存记忆、清空后检索完成；自动冲突保护失败，原始失败保留 |
| 第三章材料 | 8 张交互阶段 PNG、263.24 秒主录像；46 次真实模型服务请求/响应 |
| 重启回看 | 两个项目关闭后的记录、截图与视频仍可打开 |

第三章失败属于被测 PaiCLI 的业务行为：首次保存 JDK 21 被冲突检查拒绝后，内层 Agent 自行调用替换参数覆盖 JDK 17。没有恢复旧值后再挑通过结果，也没有为通过本次案例修改 PaiCLI。自动上下文压缩的多个分支未被短案例触发。

## 可重复的自动化检查

从源码仓库运行，先准备 Python Playwright、Chromium、FFmpeg/ffprobe，以及 Node.js 20+：

```sh
npm test
npm run test:pty
npm run test:pack
```

- 图片替换：13 项，包含代码块、正文、并发编辑、符号链接等边界。
- 宿主集成：4 项，用测试注册器驱动真实 Python 终端，覆盖协议、权限、取消和关闭/重启后的编号与素材保留。
- 索引写入：1 项，验证并发更新后仍是完整 JSON，无临时文件残留。
- PTY 检查：真实输入、多行、文件字节、PNG、MP4 解码、连续退出码、SIGTERM 清理、大终端视口。
- 打包检查：解包到独立目录，重新检查依赖、真实 PTY 和空 HOME 示例。

空 HOME（临时用户主目录）与最小 PATH 的测试仍复用已安装的 Python Playwright 和 Chromium，证明不依赖 Codex 或私人配置，不能描述成新机器无需安装依赖。

## 已知限制

1. 只实际验收 macOS。Linux 使用相同 PTY 实现但尚未独立验证；Windows 未实现。
2. 桌面实况采用周期刷新图片，不是完整的文本终端控件。
3. 只换图支持简单的独占一行 Markdown 图片；复杂写法会拒绝。
4. 只有受控 Bash 能记录命令退出状态；交互程序内部命令和其他 shell 可能未知。
5. 本次 Python 运行的 `paiwarp_close` 即时回复带运行器退出码 0，但 `run.json.runtimeExitCode` 保留 null。以缺失处理，不把 null 当成 0；被测 Python 两次退出 0 有各自 Bash 状态佐证。关闭交互 Bash 的 SIGHUP 是另一个状态。
6. `doctor.py` 目前显示 Python 版本但未严格比较最低版本，请自行确认 3.9+。
7. 与某一版 Harness 兼容，不代表未来宿主接口变化后无需更新。

遇到新问题请附可复现步骤和脱敏错误，在 Issues 中区分“插件输入/保存出错”和“被测程序业务失败”。
